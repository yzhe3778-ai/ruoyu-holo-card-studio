# 来源与个人版本

个人版：ruoyu-holo-card-studio，若愚 · 全息闪卡工坊，版本 1.0.0。

派生自 https://github.com/EverettFish/holo-card-studio ，基线提交 7d09e040427319d291164f0c1ac78f8ca0638f18，加上本地 Blender 5.2 兼容修正。原作者/贡献者版权及 MIT 条款完整保留在 LICENSE；不冒称上游原创或官方版本。

增强范围：通用材质预设、二维构图配置、哈希缓存、断点续跑、批量入口、覆盖保护、设备检测和素材检查。源项目角色图片不加入分发。

使用本地 Blender CLI 即可，无须连接 Blender MCP；MCP 不是高质量拆图的前提。

## 1.0.0 验证记录

2026-09-09：13 项回归测试、Skill 格式校验和 JavaScript 语法检查通过。以独立测试目录内的善逸素材完成真实 Blender 构建、渲染和 GLB 导出，重复执行命中构建与导出缓存。批量测试分别记录正常项目成功和缺失配置项目失败。浏览器实际检查正反面，修复背面文字镜像，控制台无错误或警告。

技术构建通过不等于视觉验收通过；新素材仍需逐卡检查拆层质量。批量入口只负责已准备素材的构建，不自动生成图集总览页面，也不把生图重绘宣称为保留原像素的抠图。
